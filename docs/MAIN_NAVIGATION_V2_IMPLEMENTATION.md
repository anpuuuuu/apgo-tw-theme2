# 主導覽結構規格 v2｜實作與預覽流程

## 目標

依《主導覽結構規格 v2》建立可在 Shopify Draft Theme 獨立預覽的版本，不直接修改或發布目前的正式主題。

## 原則

- 主導覽層級與連結由 Shopify「內容 → 選單」管理，Liquid 不寫死活動或分類連結。
- 桌機下拉選單以點擊開關；點擊外部、按 `Esc` 或開啟另一個選單時關閉。
- 手機沿用漢堡選單的階層操作，首頁連結只在手機顯示。
- 導覽固定置頂，洗衣精訂閱制可由選單設定指定為品牌色項目。
- 首頁商品由 Theme Editor 選擇；缺貨或下架的手選熱銷商品不輸出。
- 本分支只推送 Draft Theme；正式發布需另行確認。

## 驗證流程

1. 執行 JSON/Liquid 靜態檢查與 `shopify theme check`（如環境可用）。
2. 本地檢查桌機 1440px、平板 768px、手機 390px。
3. 驗證選單只在點擊時開啟，鍵盤與 `Esc` 可操作。
4. 驗證缺貨商品不顯示、商品連結正確、加入購物車後數量更新。
5. 推送 GitHub 預覽分支。
6. 建立 Shopify Draft Theme，驗證首頁、商品頁、購物車與結帳入口。
7. 提供 Preview URL；不發布為正式主題。

## Draft Theme 驗收條件

- 正式主題仍維持原 theme ID，不被發布或覆寫。
- Preview URL 可在未登入後台的視窗開啟。
- 桌機與手機皆可瀏覽導覽層級。
- 商品可加入購物車、修改數量、進入結帳。
- 缺少後台內容時以空狀態或自動隱藏處理，不輸出破版卡片。
